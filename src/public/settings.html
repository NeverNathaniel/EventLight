Add a Venue by URL

Paste a venue's website. EventLight checks for a VenuePilot ticketing widget, a WordPress or Squarespace events listing, an RSS feed, an iCal feed, then embedded event data (JSON-LD) — and only falls back to scraping if none of those exist.

Favorite Artists

The strongest signal. When a favorite is on a bill — headlining or opening — it's a pick, however far out the show is. EventLight also looks up who sounds like your favorites (via ListenBrainz) and boosts those shows, so the more favorites you add, the better the discovery.

Genre Weights

Each genre you weight (1–5) boosts matching shows in Top picks and Explore’s Best match sort. Events are matched on their listed genres plus genres looked up for the artists on the bill, so scraped shows count too. A weight matches more specific tags ("punk" matches "pop punk"), not broader ones.

Close to Home

Shows you'd like anyway rank higher the closer they are to home: the full boost within about 8 miles, fading to none by 18. It only scales a show's existing score, so a nearby show with no match to your taste stays out of Top picks.

Learned Signals

Genre tags picked up from shows you mark Going or Maybe (fading with an 8-week half-life), plus the artists themselves, which count like favorites. Hiding an event gently demotes other shows by the same headliner.

RSS / iCal Feeds

Edit feeds.json without touching code. Disable a feed to skip it on refresh; the URL note flags any that may need verifying.

Web Scrapers

Venues without a feed or API. Toggle one off if its selectors drift; the dashboard’s top line and Refresh & status below flag failures. Run scrapers below after editing.
